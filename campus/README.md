# 科大云宇宙 源码

[项目展示与试玩](../README.md) · [项目介绍](../docs/PROJECT_INTRO.md)

Godot工程位于 `godot/project.godot`，地图配置位于 `godot/data/`，Blender生成器位于 `blender/scripts/`。

## 斜坡 PR 基线的性能与网页版本

此分支从 PR #1 合并提交 `372e197` 开始。道路、斜坡、地图原点与碰撞保留该版本；渲染优化使用空间批次、原模型 LOD、多方向远景、阴影分级及按可见水面调度反射。原生 Forward+ 的分辨率、抗锯齿和阴影贴图尺寸保持原设置。

六机位实测数据见 `docs/runtime_optimization_pr1.json`，十分钟、15 位 NPC 的实际操作结果见 `docs/runtime_traversal_pr1.json`。完整机位截图和原始帧数据保存在本轮工作区的 `performance-web-work/pr1-rebuild/`。

设置 `GODOT_EXE` 为 Godot 4.7.1 后，用 `run_game.ps1` 启动原生游戏。`--runtime-before` 可临时关闭本分支渲染策略进行对比。

网页构建使用同版本的单线程 Web 模板：

```powershell
./export_web.ps1 -GodotExe $env:GODOT_EXE -PythonExe python -TemplatesDir '<Godot 4.7.1 模板目录>'
```

脚本顺序执行导入、原地图静态分区烘焙、导出、源码哈希校验与 HTTP 压缩；输出目录包含 `current.json`、版本目录及 `upload-manifest.json`。烘焙后的 `.scn`、共享 `.res` 与模型缓存不进入 Git，可由构建脚本重新生成。网页先加载起始分区，接近新区或前往远处 NPC 时再加载对应区域，离开远区后释放场景。下载使用浏览器异步读取，校验成功后才布置场景。

网页画面使用 Compatibility / WebGL 2，支持完整 15 人名单、中文筛选、跨区前往、对话与手机横屏控件。真实 Android、iPhone 与普通网络的最终验收需要单独记录，桌面窄屏测试不替代真机结果。

科大 API 配置位于本机 `ai/.env`，密钥、虚拟环境和嵌入模型不包含在网页资源中。网页 AI 通过已授权的独立中继连接本机服务；启动与停止见 `ai/README.md`。不需要 AI 时关闭服务可释放约 2.7 GB 内存。

本机 Windows 独立成品的交互检查通过，但退出阶段仍触发已安装 `wintab32.dll` 的访问异常；该安装包尚未完成验收。源码启动版十分钟测试正常结束。未修改系统驱动或其他程序的配置。

## 网页加载与连接恢复

网页使用固定版本的资源地址。引擎和 PCK 按最多 16 MiB 的压缩分段下载，每段 SHA256 校验后保存，重新进入时复用已完成的分段；不支持流式解压的旧浏览器继续使用原下载方式。缓存被禁用或空间不足时仍可联网加载。

地图保留原几何与碰撞，以最多 96 个顶层节点的小块布置。初始化进度界面下的目标工作预算为 35 ms，进入校园后降至 3 ms；单个资源解码或着色器编译仍可能超过预算。下载并发上限为 3，网络异常与校验失败有限重试，失败时保留当前位置并提供重试。主动前往 NPC 优先于尚未开始的后台区域请求。

NPC 动画在构建时预生成；交谈界面在加载阶段预热。Web 对话沿用场景照明，避免新增方向光引发一轮材质编译。AI 请求异步执行，失败后保留问题并可重连。HTTP 530 等隧道故障由网关转换为明确的离线状态。

Web 预热界面期间关闭 3D 绘制，并移除原生版的两个全场景反射探针，继续使用天空环境反射。平面水面反射只在屏幕采样确认水面可见时更新，交谈面板打开期间暂停更新；地图模型和纹理保留。

WebGL 首次绘制现在先在 64×64 独立视口中按材质与顶点格式逐帧预热，再显示分区。相同自定义着色器代码共用程序，各材质颜色、纹理等参数继续独立；进入就绪信号等待实际首帧完成。可选浏览器长任务日志记录真正的主线程阻塞，不把后台标签限帧当作卡死。

网页版的人物搜索、提问和向导目标使用浏览器原生输入框，与现有游戏状态同步，保留中文组合输入、粘贴、回车和 Esc 操作。手机虚拟键盘仅在触屏且主指针为粗指针时启用。浏览器不允许锁定鼠标时，聚焦游戏画面后仍可键盘移动，并通过按住鼠标左键拖动转向；原生版继续沿用原控制方式。

配置好[网页 AI 后台](ai/README.md)后，在仓库根目录用 PowerShell 执行 `.\campus\ai\run_web_ai.ps1 -Watch` 启动监控；用 `.\campus\ai\run_web_ai.ps1 -Stop` 停止监控及其启动的服务。AI 需要主机在线并连接校园网；普通校园漫游可独立运行。
