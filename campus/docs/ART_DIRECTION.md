## 色板与材质

| 用途 | sRGB 设计色 | 关系 |
|---|---|---|
| 天空 / 云亮部 | #ABCBD8 / #F3EBDA | 柔蓝承托暖白，避免纯白过曝和积木云 |
| 红砖 / 石材 | #B77B64 / #C5BCA4 | 暖砖红主体，米灰窗台、路缘与入口相连 |
| 植被明 / 中 / 暗 | #97AA66 / #738D4C / #425B49 | 大尺度色差，内部阴影保留绿灰层次 |
| 樱花明 / 中 / 暗 | #EED2C6 / #D9A8AB / #AD788A | 粉白花团、灰紫内部、少量嫩叶 |
| 玻璃金属 / 木材 | #465B64 / #82705A | 深青灰和低饱和暖棕统一小品 |
| 阴影 | #71828E | 冷灰蓝；不画黑边或强青蓝阴影 |
| 人物主色 | 灰蓝、薄荷、陶土、米白、炭灰 | 小面积识别色；不争夺花团和红楼的主体地位 |

这些是设计关系，不是最终屏幕逐像素色值。材质保留 Base Color、Roughness、Normal、AO 与克制色差；NPR 采用柔和层次，接受环境光与阴影。纯色塑料、过重黑描边、强两档明暗和高频脏污都不作为本项目基准。玻璃有暗内部、天空/植被色影响和 Fresnel，不能退回蓝色贴纸。

## 几何与景观规则

- 建筑按 Macro → Meso → Micro：先 U 形体量、四层比例、入口与窗列，再凹窗、窗台、檐口、墙根、台阶及倒角。背面与侧面也必须成立。用几何厚度吃光，避免通过随机微细节补救简单盒子。
- 树木按树干 → 主枝 → 次枝 → 大簇 → 中簇 → 小强调簇。樱花横展分层，梧桐高挑宽冠，普通乔木纵向紧凑；同树种个体改变轮廓和枝向。保留连续曲率、内部层次、透光与树影，不用换色代替树种差异。
- 铺装、草地、路缘、台阶、排水与树池形成连续边界；草地大色差配局部草簇，不均匀撒满全场。入口与停留点有细节，视线走廊和大草地有留白。
- 小品使用统一木色、灰蓝金属、米灰石材；长椅、自行车架、公告栏、灯具应服务具体停留行为。路边休息长椅前不自动放学习桌。

## 人物与生命

Hero 允许比 Ambient 更明确的面部与成人半 Q 比例，二者共享材质、轮廓柔度、服装色板与人类尺度。做题家已验收的窄长脸、下颌、矩形镜框、寸头、克制眼睛和胡茬是冻结身份；不因新增角色重新生成或圆化。Ambient 是原创校园角色，不套用 Hero 的具体脸；动物保持小体量、安静节奏。

0.5首轮实机审查发现既有拍照/背资料角色仍是积木式 Q 头，与新骑车/后院读者不统一。因此四套 Ambient 改为同一生成器和连续成人化剪影体系：当时新增的是两个故事节点，另外两个保留位置与角色功能、升级外观，不是新增四人。做题家8项受保护文件哈希保持不变。历史真实对照见 [population/review.html](../renders/population/review.html)。

0.7保持4 Hero + 6 Ambient + 4 Creature。三月七在北轴摄影走廊、豆包在老北门附近慢读，另三位在既有范围漫步；站立角色的脚步应由真实腿脚支撑，箱子与落叶留在故事点。长椅写题、后院坐读与原趴猫保留安静停留，不要求所有节点行走。见 [WANDERING_BEHAVIORS.md](WANDERING_BEHAVIORS.md)。

动作以停顿为主，呼吸、抬眼、扶镜、翻页、拍照、低速骑行与猫鸟微动只在局部可读。树冠、草、云、水、花瓣和光照变化幅度小且错相；镜头内通常只有一个明显动作中心。数量与分区见 [SCENE_POPULATION_RULES.md](SCENE_POPULATION_RULES.md)。
