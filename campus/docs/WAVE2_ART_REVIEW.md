# 第二波扩展：实机艺术复核

2026-09-08。只评价此次相邻扩区和五个新故事；既有做题家、校园建筑、树木资产和Shader源文件以冻结哈希回归。新角色是校园 cameo，不把本轮自动验证等同于用户已经接受角色设计。

## 比较方法

官方参考 → 文字身份锚点 → 生产模型正面/3/4/侧面 → Godot 4K近景与环境镜头。完整第一轮实机图保留在 `renders/wave2/round01/`，最终版本保留在 `renders/wave2/`；两轮均为原生Godot渲染。Blender接触证明由实际Godot骨骼矩阵驱动，没有另摆一套更漂亮但无法实机复现的姿势。

## 第一轮发现与修正

| 实际观察 | 对观感或叙事的影响 | 本轮修正 |
|---|---|---|
| 新角色近景多朝向展台外，灰色背景占很大面积 | 人物像独立陈列品，校园故事背景不足 | 只调整五个新角色的朝向和机位，使身后的红楼、草地、道路进入构图；位置仍来自同一部署数据 |
| 豆包分束头发像一排梳齿，眼部叠层凸出 | 官方头像的偏分bob身份被玩偶感盖过 | 改连续不对称短发壳、细分缝线，封顶并减薄虹膜/瞳孔层；保留黑圆领和浅内领 |
| 袋鼠与豆包的屏幕朝向观众 | 角色实际上看不到所“阅读”的内容 | 屏幕改朝向角色，按屏幕局部坐标求手部目标；豆包指尖沿一行文字缓慢移动 |
| 开箱动作下只有一个实心盒子 | 手臂有动作却没有真的检查箱内的空间 | 增加内底、四壁、保温层和简单餐盒，箱盖与提手围绕同一个铰链 |
| 猫伸爪时整条前腿平移，叶片略浮空，尾管切口可见 | 身体结构和地面接触不可信 | 腿从固定根部转动，落叶底面约离地1mm，尾端封口；动作如实命名“伸爪试探”，不声称爪已压住叶片 |
| 读资料和闻落叶时头部实际抬高 | 状态名称与姿态相反 | 依据角色朝local -Z的实际骨骼，纠正X旋转方向；用鼻尖位移核对读/闻确实低头 |
| 道路转角有三角草地缺口 | 连通地景看起来像断开的铺装碎片 | 保留同一道路中心线，整条折线生成连续圆角铺装；旋转长椅下的承托铺装以匹配椅脚 |

## 身份与风格判断

- 雷电将军的长紫辫、侧花金簪、白紫交襟、大腰结是优先锚点；读书与停顿属于校园改编。三月七用粉白短发、蓝白分层衣着、花形徽饰和实体相机区分，两个角色的头脸与眼型也做了分离。
- 美团袋鼠保留长耳、大黑鼻、小眼、奶油袋口与长尾，黄色是小面积视觉焦点；不会额外摆广告墙。
- 豆包依据官方头像，身体和校园平板共读行为为原创补全。头像分辨率有限，当前是简化的校园伙伴，不能称作官方全身精确复刻。
- 新猫服务于路边微小事件，原长椅猫仍保留。新旧角色密度一起检查，不通过隐藏旧角色来人为通过密度门槛。
- 新增三片地面合计4,833.5㎡，沿真实相邻道路与花园，避开已知建筑和郭沫若广场中央水池。新增小品按路缘、树下和停留点组织，长椅前没有额外桌子。

## 证据与边界

第二轮15张3840×2160原生截图已经逐组查看。03/04、05/06、07/08、09/10与11中的背景已回到校园内，低头、箱腔、锚定猫腿等首轮问题已修正。12–14更适合说明连接与景色密度：宽图里人物小、部分前景树会遮住远处角色；01仍保留大量灰色展台背景，不能将每张宽图都称作角色宣传特写。

最终完整场景14项检查通过，旧核心993地面采样和8条草地路线保留，新区域4,615个墙体内部以外的地面采样、4条新连接路线及3处外边界穿越测试通过。五个角色总计150秒/1,800帧的Godot动作序列已编码；原帧中实际比较了三月七放低/举起相机，另抽看雷神读书和袋鼠开箱。MP4由Blender解码检查首、中、末帧及分辨率/时长，结果见 `video_validation.json`，未把抽帧检查冒称逐帧观看。

完整物理、局部人数、原资产哈希、循环和手脚接触以 `renders/wave2/validation.json` 为准；吉祥物屏幕朝向、低头符号和爪叶距离另见 `mascot_contact_review.json`。人物轮廓和IP识别仍需人工看图，自动QA只证明对应的技术事实。

角色几何与服装已经校园化简化，仍不等同于原作高精度模型；豆包的小头像补全和衣饰微细节是后续可以继续精化的部分。本轮不以扩大面积或增添更多IP掩盖这些差异。下一次扩区继续沿模块接口推进，先核对真实地图、固定机位和全量人物密度。
