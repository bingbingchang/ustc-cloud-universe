# 地面连续性：修复与后续扩建约定

本次确认的根因是 `diorama.gd` 中旧核心区的可见草地使用了四边缩进10厘米的矩形（x±79.9，z118.1～237.9），碰撞板与扩建区则以完整矩形（x±80，z118～238）相接。低层底座在Live版本隐藏后，这类缺口尤其明显。此前较稀疏的地面物理采样无法发现可见网格缺失。

修复后的可见草地与碰撞板均从 `NorthAxis._core()` 获取边界。草地使用共享的分块裁剪器，扣除湖水及北区已经拥有的范围；既不靠大幅重叠掩盖缝隙，也避免两块同高地面重复覆盖产生闪烁。此修复在共享Diorama基类中生效，当前Live、樱花、亭桥样段和扩展湖园均继承它。

## 扩建规则

1. 先定义完整区域边界，再生成可见地面与碰撞；两者从同一份边界数据取得尺寸。不要为底座美观缩进可见顶面。
2. 相邻区域共享精确的边界坐标和地面高度，不手填“差不多”的端点。需要高差时建立明确的坡道或台阶。
3. 重叠区明确由一个区域拥有；扣除另一块地面的重叠部分。水体、岛与保护区使用同一套裁剪定义。
4. 新区域登记在模块布局中。可见接缝检查自动读取核心、北区和启用模块的多边形边界。
5. 每次地面、边界或模块布局变更后，运行 `check_ground_seams.ps1`，再运行原生行走与禁入检查。两种检查都要通过。

## 新的回归检查

`tools/validate_ground_seams.gd` 从实际可见草地三角面建立独立射线层，沿区域边界每0.5米取点，在边界两侧分别偏移5、25、75毫米。射线只检查y=0附近的可见地面，碰撞板不能遮蔽漏洞。排除湖水与保护区。

本轮复现旧缩进边界时，12,834个有效采样点中4,086个未命中可见地面；修复后Live扩展湖园与Diorama均为12,834点零缺口。它们是失败采样点数，不是独立裂缝条数。

结果位于 `renders/ground_seams/`。旧问题复现参数为 `--simulate-old-ground`，应返回失败；普通检查应成功。

该检查覆盖已登记区域边界附近，不宣称能发现任意宽度、任意位置的所有网格缺陷。新增内部裁剪缝、地面高差或新区域类型时，需要补充相应采样与视角；保留原生地面及行走回归检查。


完整回归：本轮Live扩展湖园与Diorama的8组原生检查均通过，包括各17条连续路线与9处禁入。结果另存于本目录对应的 `renders/ground_seams/live_routes.json` 和 `diorama_routes.json`。历史115个GLB、贴图及布局文件保持不变，修改集中在共享地面生成逻辑、接缝检查和新增种植。
