# 做题家小伙 · 设定身份回到实机

日期：2026-09-08。范围仅为既有长椅版的身份修正，以及通过内部近景审查后制作的同身份蓝白校服变体。不扩建校园，不增加成批 NPC。

本轮最高优先级是用户已认可的 [Character Sheet](../../../references/characters/tiku_boy1/character_sheet.png)，原始 [Primary Reference](../../../references/characters/tiku_boy1/primary_reference.png) 继续作为身份源头。设定稿、Blender 生产资产渲染、Godot 实际截图分别标记，不能互相替代。

## 旧版为什么丢失人物身份

旧 Godot 近景只保留了“眼镜、蓝衣服、写字”标签。头部均匀椭圆化，额头、颧颊和下颌没有明确转折；眼睑像粗横条，眼白像独立小圆柱；粗折线镜框接近八边形。鼻子、嘴与规则排列的胡须缺少设定稿中的生活感。头发是一块停在头顶的黑帽，白领像两块竖起的硬片。

这些问题不是单独换 Shader 能解决的。旧版技术可运行，但其具体脸部身份不成立。

## 第一阶段：长椅版修正

生产构建仍由 [build_tiku.py](../../blender/scripts/build_tiku.py) 完成，共用的头部实现拆入 [tiku_head.py](../../blender/scripts/tiku_head.py)。

| 身份项 | 本轮实际改变 | 检查重点 |
|---|---|---|
| 头部 | 重新建立额头、眼眶、颧颊、下颌与短平下巴；鼻梁、鼻尖和鼻翼连续造型 | 正面避免蛋形，3/4 与侧面仍保留同一骨相 |
| 眼睛 | 绘制眼白、上下眼睑及疲惫层次；瞳孔由材质内的位置控制 | 窄眼、低开合、短暂侧目，不能再变成粗黑条 |
| 眼镜 | 较薄的横向圆角矩形框、独立镜腿 | 镜框识别明确，同时不遮住侧目 |
| 鼻唇 / 胡茬 | 连续鼻唇体积配合绘制底色，保留薄唇与稀疏不规则胡茬 | 不默认微笑，不用规则栅栏式胡须 |
| 短发 | 发际线有额角变化，包覆鬓角及后脑，增加细微短发质感 | 避免简单黑半球，侧面接缝仍需继续精修 |
| 衣服 | 白领缩短，肩宽收敛，袖口及衣身轮廓调整 | 简化真实衣服，保留浅蓝毛衣与白领组合 |
| 手与书 | 手掌、弯曲握笔手指和书本接触关系进一步调整 | 一手固定本子，一手写字；本子在腿上，长椅前没有桌子 |

设定稿文字标注约 **6.5 头身**；当前三维身高约 1.78 m、头部约 0.31 m，实际约 **5.7 头身**。该比例处于用户要求的成人半 Q 版范围，兼顾微缩场景中的脸部可读性；它不等于逐笔、逐比例复制设定稿。体型保持偏瘦，不使用圆脸、婴儿肥、腮红、巨大亮眼或蘑菇头。

面部纹理 [tiku_face_albedo.png](../../godot/assets/textures/tiku_face_albedo.png) 使用内置 imagegen 基于已认可设定稿生成，再映射到三维头部。它提供眼睑、眉毛、嘴唇与胡茬等绘制细节；鼻唇、头骨、镜框和短发仍具有三维体积。没有把公开网络照片的脸直接裁贴到模型上。生成原文件为 `C:/Users/ysy2c/.codex/generated_images/01a07c94-24c0-7963-bc4a-e74532253d75/exec-f9390a02-b49d-4e1f-b96f-26be01a41443.png`；提示词记录为 [face_albedo_prompt.txt](../../../references/characters/tiku_boy1/face_albedo_prompt.txt)，与最终纹理分开保留。

Godot 使用相同脸部 UV 逻辑保留底色，并让瞳孔在表面内移动。面部仍接受校园光照、树影和环境色，不以不受光的固定图片替代角色。

长椅主循环保留写题、停笔、思考、左右短暂观望、眼先动的侧目、扶镜、翻页与小幅疲劳动作。躯干和头部向本子微倾，动作间留停顿。玩家经过触发是带冷却的泛化注意力分支，不根据真实人物照片推断性格，也不把互联网昵称转化为生理诊断。

## 第二阶段：同身份校服变体

内部先检查新长椅版 Godot 正面、3/4、侧面和真实坐姿，确认脸部身份已明显收敛，再生成 `tiku_boy1_uniform.blend` 与 `tiku_boy1_uniform.glb`。第二阶段不是重新设计一张通用学生脸。

两版共用 `tiku_head.py`、面部底色、眼镜与短发几何，体型和头身比保持一致。变化限于蓝白运动外套、袖条、运动裤细条、持书姿势和场景位置。

校服裁片的具体视觉依据是用户已有的 [蓝白校服写题参考](../../../references/characters/tiku_boy1/c63b2f20-14ae-4fdf-a269-07242beac118.png)：米白肩胸、蓝色腹部，胸前 V 形拼接向上臂延续，白袖配蓝条及蓝色收口袖口，短白翻领和中央拉链。衣身适度宽松，朴素规整。此角色衣着不声称为中国科大的官方校服，也不复制其它学校校徽。

路边微型叙事采用左臂夹一本闭合教材、轻微换重心、抬头与呼气、短暂侧目、右手轻推镜框。书与左肋、左臂保持支撑关系；站姿不应成为军姿或大幅装酷表演。初轮校服实机审查发现角色踩到树根、夹持的书仍像竖起的展开练习册，因此后续移至路缘铺装并改为闭合教材。最终展示只引用最后更新的同名捕获文件。没有找到可可靠近看的官方“腋下夹书”照片，具体姿态作为原创动作设计记录。

## 证据与复现

本轮 [review.html](../../renders/tiku_identity/review.html) 将以下材料放在同一页：

1. 设定图中性脸局部、旧 Godot 近景、新 Godot 正面与侧目；局部仅由 CSS 裁切，原 PNG 未被重绘或编辑。
2. Godot 长椅版正面、3/4、侧面、背面、实际坐姿、校园近景和扶镜动作。
3. 校服版静态正面、3/4、面部近景，以及路边思考、侧目、扶镜截图。
4. 两套 Blender 正面、3/4、侧面、正脸近景、3/4 近景。影棚直接读取生产 `.blend`，仅添加相机、地面和灯光、暂时隐藏书与笔，不保存源文件。
5. 长椅版与路边版各一段完整 32 秒 Godot 循环视频及动作验证报告。

静态捕获目标为 Godot 1920×1440、Blender 1200×1500；循环视频目标为 1280×720、20 fps、640 帧、32 秒。**这些是捕获配置，完成情况以实际文件和报告为准**；画廊对尚未产生的材料显示待生成，不冒称已验收。

使用 `python campus/tools/tiku_identity_review.py` 刷新展示页。该脚本只读取产物并写 HTML，不修改图像、不渲染模型。Blender 影棚脚本为 [render_tiku_proof.py](../../blender/scripts/render_tiku_proof.py)，追加 `-- --uniform` 切换校服资产。

最终验证结果见 [animation_validation.json](../../renders/tiku_identity/animation_validation.json) 与 [identity_validation.json](../../renders/tiku_identity/identity_validation.json)。17张Godot截图、10张Blender截图和两段32秒循环已经产生。两套实际导出的头部位置、法线、UV几何SHA256完全一致；1282个姿态采样有限，两个32秒循环首尾位置与Basis误差为0，握筆点最大误差约0.00000014米，纸面接触距离1毫米，双臂IK误差小于0.000001米。基础循环闭合检查排除外部玩家注意力事件；数值检查不能替代艺术审查。外部玩家绑定已移至场景初始化结束，真实游览靠近可触发短暂侧目。

最终校服站位为(3.4,0.978,145.0)，在东侧铺装路缘、路灯附近。先比较四处实际日照机位，再选择此处，避免树根穿插和浓影压平面部；不是用截图后期修改角色。人物近景阴影距离60米，步行80米，整体微缩摄影400米，保证远景与近景各自需要的精度。最终捕获使用Forward+、Ultra阴影/SSAO/SSIL设置。运行日志无SCRIPT ERROR/ERROR；Godot退出仍有原有的7个Texture RID未释放警告，未阻止运行和捕获。

## Art Review：当前结论与保留问题

新角色不再只靠“眼镜 + 蓝衣服”识别。新实机正面可读到窄长脸、明确下颌、短发额角、矩形眼镜、克制眼睛、鼻唇和稀疏胡茬；坐姿近景仍能保留这些特征。第一阶段达到继续制作同身份校服变体的内部审查条件。

距离设定稿和最终高品质人物仍有明确差距：

- 肩肘仍能看出分件与刚性转折，尚不是完整蒙皮衣服的连续形变。
- 短发侧面的局部接缝与头皮衔接仍需精修，侧面必须继续复核。
- 三维约 5.7 头身与设定稿标注 6.5 头身不同；脸部笔触、轮廓和细微神态不是逐笔一致。
- 手指并非逐指完整绑定，纸页与笔的互动依赖有限程序约束。
- 当前高精度源模型单角色约23.5–29.3万三角面、14种材质，不称作低面数资产。后续在身份稳定后制作明确的角色LOD和减少材质拆分，不能直接扩成大量同精度NPC。
- 校服蓝白对比比设定稿更强，近景镜架阴影仍较硬；仍可继续收敛色彩与人物填光。
- 不宣称当前角色已达到动画电影最终成片。后续优先处理衣服连续变形、侧面短发衔接与手部接触质量，避免以增加 NPC 数量掩盖质量问题。
