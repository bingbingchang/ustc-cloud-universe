# Hero LookDev / Environment Art Review

地图冻结：保留原V0.1坐标、建筑布局和样板边界。当前阶段只处理玉泉北路、双池与一教前场的视觉质量。

## 基线诊断

1. 树冠里可见低分段椭球，叶片只是装饰在外，内部暗面读成实心石块；枝条放射规则，三个资产反复复用。应移除壳体，用真实分枝和有空隙的叶簇建立体积，按树种与个体改变生长架构。
2. 一教为整面实心盒体，玻璃和窗套堆在外侧。缺少窗洞负空间、窗台厚度、分层檐口与基座；只能读出平面矩形。应重做主要立面墙段与凹窗，保持真实四层平顶建筑轮廓。
3. 所有物体共用同一shader，固定AO和roughness令玻璃、石头、木头缺少材质区分。应分别建立多通道表面、玻璃和透光叶片响应。
4. 路面大尺度单一，草与树都是相似明度绿色，缺乏低层灌木过渡、路缘厚度、树池、排水与铺装分区。
5. 云以几个重复椭圆叠加，缺少透射和体积阴影；太阳与固定环境色令前后景处于相近明度。应建立体积云、天空填充、局部反射与接触阴影。
6. 机位01过于正中、02前景荷叶过大且背景楼过空；宣传图要建立明确主体和前中后层次，同时保留同机位对照，不能仅靠换镜头证明资产改善。

## Color Script

清朗下午：天空使用略偏灰的青蓝与远处暖白；建筑为低饱和陶砖、暖灰石和中性灰绿玻璃；绿植使用冷暗绿、灰橄榄中间调、适量黄绿受光边缘。避免三种独立高饱和纯色互相争抢。阴影保留蓝灰天光，远景压低对比，主体立面保持温暖。

## 验收流程

基线PNG保存在 renders/lookdev_before。每轮记录实际画面问题与修改。最终至少3–5个地面机位输出高画质PNG；除空间与功能回归，另行评价轮廓、材质区分、光照层次和画面构图。视觉未达标不能用通过测试或帧率代替。
