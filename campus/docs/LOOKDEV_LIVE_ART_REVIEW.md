# LookDev Live：同内容对照与实际修正

2026-09-08。目标是让两种视觉表现拥有相同校园内容，便于选择后续主方向。没有重做或重新接受已完成的角色身份。截图来自 Godot Forward+ 原生 3840×2160、8×MSAA / TAA；并非后期生成图。

## 观察与决定

| 观察 | 原因与处理 | 实机复核 |
|---|---|---|
| 旧 LookDev 更容易读成可进入的校园 | 1.65m 眼高、透视、细叶间隙、细碎树影、较小倒角和清晰砖纹共同提供尺度线索 | `01_hall` 与 Dio 同位置/FOV比较；保留人高作为 Live 默认入口 |
| 简单加载旧 architecture 会把过时门、池、亭一起带回 | 旧资产按材质合并，不能只凭文件名认为它只是“一教” | 独立提取旧一教；门、双池、四桥、一鉴亭和周边楼只读取新北轴资产 |
| 旧入口台阶与当前承托方向不同 | 视觉台阶曾向广场反向抬升 | 用当前四级台阶/平台替换；12 点真实几何与碰撞高度一致 |
| 换细叶树后，树旁遇到过大的隐形阻挡 | 贴地根宽被挤成统一高圆柱 | 复用9个树变体的真实低段树干三角形，103棵/412截面最大偏差0.0000458m；没有提高容差 |
| 高空总览过灰、远景草地形成重复花纹 | 人高雾密度不适合400m级距离；小纹理复制到整片背景 | 摄影高度15m以下保留原雾，升高后逐渐降低；范围外地面改低对比、非周期的大尺度色差 |
| 直接去掉底座会露出断边，也会让不可走范围失去提示 | 展示边框同时暗示了场景边界 | 隐藏展示底座，背景地面和既有远楼做视觉延续；所有外边界对应可见细栏杆 |
| 换环境容易让已接受角色失去身份 | 通用环境 shader 不能替代专用脸部和衣料处理 | 原角色 GLB、脸纹理、毛衣/校服专用 shader 保持；`07_tiku` 检查窄长脸、矩形镜框、衣领和腿上写字，没有添加长椅前桌子 |

## 机位用途

优先看 `01_hall`（一教与人的尺度）、`04_bridge`（新亭岛/双池与树叶）、`07_tiku`（身份保持）。`03_gate` 检查老北门与轴线，`08–15` 检查人口与环境的关系。`06_pools`、`16_whole` 用于空间对照，不代替人高画面，也不作为完整东区已完成的证明。`17_routes` 是行动线检查图，正常游玩默认隐藏。

两套17张图片使用相同相机变换、FOV、投影、正交尺寸、动作时间和分辨率；灯光、季节、植物结构和材质有意不同。由 `comparison_validation.json` 验证相机条件，不能把“同机位”误写成“灯光也完全相同”。

## 完成范围与剩余局限

内容方面，14个生命节点、五位漫步、路线显示、北轴重建、草地承托和原有设施已共用。模型仍有两套视觉选择：细叶与冠簇、细倒角与圆润边缘、旧一教立面与 Dio 追加的后立面/女儿墙；Live 没有宣称把所有 Dio 建筑装饰逐件搬回旧模型。

LookDev 仍是半写实 NPR，远处楼体和草地延续只服务空间背景。程序树的分枝规律、部分灌木的概括形状以及 cameo 角色的简化程度仍可见。外围栏杆是当前样板范围的游玩提示，不是学校真实围栏的测绘复原。新增外围背景不构成可游览面积扩大。

64秒影片用于展示八个环境/漫步片段，原始帧是1280×720、12fps；不是4K视频，也不代替每个角色完整周期的程序验收。视频是无声原生画面序列；交互运行保留低音量校园环境声。解码范围与最终结果见 `video_validation.json`。性能仅按 `LOOKDEV_LIVE_PERFORMANCE.md` 中1600×900普通画质条件报告，不外推至4K Ultra。

## 后续复用

从 `lookdev_live.gd → diorama.gd` 共享行为与数据；后续人口、路线、北轴布局先改共享来源。新 LookDev 视觉覆写局限在资产选择、材质、光照、镜头、范围外背景和适配后的模型碰撞。美术变化仍须各拍一套近景与场景图，不将一次同步视为以后永远无需验证。
