## 可复用模块与模板

| 模块 / 模板 | 固定复用部分 | 每个地点必须重核部分 |
|---|---|---|
| 红砖楼前广场 | 砖/石/玻璃材质，凹窗、窗台、檐口、入口踏步 | 楼体、层数、窗列、入口位置、前场比例 |
| 行道树步道 | 铺装/路缘/排水、树种族、灯具与树池 | 中心线、宽度、树冠高度密度、交叉口 |
| 樱花大道 | 多个横展花团树变体、低幅风、极少花瓣 | 真正轴线、树列间距、建筑框景、水陆边界 |
| 湖边步道 | 水材质、岸边过渡、护栏/桥栏、停留座椅 | 岸线、桥亭连接、入口及高差；该模板仍待湖区实现 |
| 草地长椅 | 连续承托地面、草簇、长椅、小灯/包/书、坐读动作 | 日照、座向、路径接地、离主路距离、节点密度 |
| 角色/动画 | 命名层级、受光 NPR、IK/接触检查、低强度循环 | 新身份剪影、行为理由、路径和局部光照 |

模板是规格与既有构造方法的复用合同；未存在的独立 `.tscn` 模板不能冒称已交付。每次实例化有 ID、边界、来源置信度、入口/出口、材质族、碰撞、人口预算和摄影点。变体用固定随机种子，避免同树同角度、同窗节奏、同角色动作机械重复。

## 每次扩段的执行顺序

1. 从 [SOURCE_LOG.md](SOURCE_LOG.md) 定位该段已读地图/卫星/官方照片；不足时只补该段资料，记录不知道什么。
2. 明确模块边界和连通端口，先灰盒；验证主路、地面、临水、楼体与人高路线。
3. 复用材质/模块做艺术处理，先形体、树影、构图，再中尺度设施；不重建冻结 Hero。
4. 配置少量人口，检查任意约100×100米范围预算；新接段可以无人。
5. 用旧机位检查质量不回退，再新增1个体现接段关系的机位；输出实际图、碰撞结果和推断。

若新面积仍像灰盒、旧 Hero 身份变差、路面不连续或性能明显恶化，先修当前段。可回退本段实例/配置，不覆盖成熟资产或用更大远景掩盖问题。
