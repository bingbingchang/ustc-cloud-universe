# 团队开发入口

本指南对应本机 `campus/` 开发版本。目标是从科大校园三维原型，逐步建设可持续联机的校园游戏，再扩展数字校园服务与共建空间。

## 先读什么

1. 本页：确定版本、运行工程、了解协作方式。
2. [代码地图](ARCHITECTURE.md)：按启动、世界、玩家、NPC、联机和资产制作理解现有实现。
3. [模块分工与迭代计划](DEVELOPMENT_PLAN.md)：查看待开发模块、接入位置、依赖和可验收的首个任务。

原有 `campus/docs/` 大量文档是各阶段记录。文件中的“最新”“下一步”、人口数和旧帧率只代表相应阶段；不要把它们当作当前团队任务表。

## 当前源码位置

本仓库 `campus/` 为当前公开开发源码，包含 15 位知识 NPC、RAG 后台、向导 Agent、最小联机和动物试验场。

- `campus/godot/`：可运行游戏、模型与配置。
- `campus/ai/`：资料检索与模型接口，运行方式见对应 README。
- `campus/blender/`：资产生成器、知识人物母版与动物制作文件。
- `docs/`：对外介绍；`campus/docs/team/`：代码地图和模块分工。

既有 `v0.1.0-alpha` 下载包属于此前校园漫游版本，新增 AI 功能从当前源码体验。

## 第一次运行

### 只运行校园：先用Godot编辑器

当前本机已运行的引擎为Godot 4.7.1标准版，工程使用Forward+。先以相同版本建立团队基线。

1. 用Godot导入 `campus/godot/project.godot`。
2. 等待资源导入，按F5运行默认场景 `scenes/campus_game.tscn`。
3. 尝试WASD移动、Shift跑步、Space跳跃、Tab切换视角、V自由相机、J人物列表、E近距离交谈。

现有模型已经随开发目录保存，普通运行不需要先重建Blender资产。AI后台未连接时，校园和NPC外观仍能运行，对话窗口会显示连接状态。

仓库根目录的 `OPEN_GAME.cmd` 和 `OPEN_KNOWLEDGE_HEROES.cmd` 调用 `campus/run_game.ps1`。启动脚本从 `GODOT_EXE` 环境变量或 PATH 的 `godot` 命令定位引擎，运行游戏不要求安装 Blender；也可直接使用编辑器。

### 修改模型的人

建模工具基线沿用已有记录中的Blender 5.2.1。模型母版在 `campus/blender/source/`，生成脚本在 `campus/blender/scripts/`；动物母版和脚本在 `campus/blender/wildlife/`。按任务重建对应资产，不需要每次重新生成整个校园。

### 做AI的人

阅读 [AI运行说明](../../ai/README.md)。入口是 `campus/ai/app.py`，不是微调实验目录。Qwen模型服务与RAG服务分开，游戏通过HTTP连接RAG服务。

按 AI 说明独立部署后台，或使用团队提供的 RAG 地址。启动时设置 `CAMPUS_AI_URL`，在 J 面板填写地址，或通过 `run_game.ps1 -AiUrl` 传入。公开启动器不连接原开发者的云主机。

### 做联机的人

阅读 [最小联机说明](../NETWORK_MINIMAL.md)。`campus/run_game.ps1` 支持 `-Server`、`-NetHost`、`-NetJoin 地址`；已有CMD提供无窗口主机、图形主机和加入入口。

当前是ENet移动与聊天原型，不包含账号、角色持久化或物品权威服务。`MAX_PEERS=16`是代码配置，不代表已经完成16人容量测试。

## 最少的团队协作约定

- 每项任务使用独立分支，通过PR合入共同主线；具体默认分支沿用仓库实际配置。
- 每项任务写清玩家能观察到的结果、主要修改文件和接入人；PR说明怎么运行、怎么检查。
- 二进制模型、贴图和场景布局按资产或区域分配负责人，避免两人同时编辑同一个 `.blend` 或同一条布局记录。
- `campus_game.gd`、`scene_modules.gd`、共享JSON和工程配置是多人会碰到的接入点。模块作者提供实现，由约定的集成人集中合入共享改动。
- 提交源码、必要运行资源、Godot UID及资源导入设置。`.godot/`、`.venv/`、缓存、日志和临时捕获帧不作为团队源码。需要复现的来源、生成参数和最终GLB要随对应资产说明保留。
- 是否启用Git LFS，先统计实际要入库的二进制文件及大小再决定；不要先为全部素材引入新存储流程。
- 验证与改动对应：UI看交互和输入恢复，场景走相关路线，动画看相关动作，RAG查召回与回答，联机用主机和客户端验证。纯文档修改不需要重跑整个游戏。

## 交接时每个人需要知道的五件事
