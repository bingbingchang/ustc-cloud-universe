# 樱花大道树池修复与西池西北岸延伸

用户截图指出树干在方形树池外。根因是两个阶段各自保存间距：旧边框来自 `lookdev_assets.py` 的 z=6+i×7.45，南段树木使用 z=123+i×7.45；旧方框与新树木没有关联。不是树模型随机偏移，也不是地图整体错位。

修复保留树木位置、碰撞和原GLB。在运行时移除既有装饰模型中6个旧树池的边框三角形，按实际8棵树的部署变换重建8个完整树池。内径取近地树根在世界坐标的最大宽度，再留16厘米土壤余量；方框、土壤与树干同中心。灌木和草的摆放排除树池范围，随机数消耗保持一致，避免顺带打乱其他种植。

## 防止复发

- 树池不能独立使用第二套间距公式。树、树池、碰撞必须引用同一部署记录。
- 更换模型或缩放后，重新计算近地根部尺寸；不能仅让树干中心落入框内、却让树根穿出边框。
- 低植被排除树池及自身展开半径，保留能看见土壤与边框的净空。
- `tools/validate_tree_basins.gd` 在真实图形运行中读取实际MultiMesh边框变换，检查中心和近地树根；不要用headless虚拟渲染器的MultiMesh读回作为视觉证据。
- 低边框高度11厘米，不增加横挡通路的高碰撞；原树干碰撞保持。

## 扩建范围

沿已有GIS西池北岸—西北转角补充2棵树、27花丛、17岸草组、56芦苇组、60荷叶群落、3石组，总树数150。复用已认可的眼镜湖参考、莫奈构图方向及原有LOD资产，不改湖岸、桥和道路，不新增地理底座。保持中央开阔倒影和通向水面的路口，北岸细节聚集在局部口袋中。西侧建筑立面仍有重复感，后续应单独精修建筑。

[四机位原生前后对照](../renders/tree_basin_northwest/review.html)。截图“before”是本轮修改前归档，后续捕获只更新after。

## 入口与复现

`OPEN_TREE_BASIN_REVIEW.cmd` 从修正后的树池近景开始，按 `]` 查看新西北岸；原优化入口也包含全部改动。树池修复共享到Live、Diorama及其派生场景。

- 树池验证：Godot `--path godot --script tools/validate_tree_basins.gd -- --lookdev --expand-west`；另加 `--diorama` 检查微缩版。实际执行时将脚本路径解析到项目的tools目录。
- 全场景检查：`tools/validate_tree_basin_northwest.gd`，允许headless物理检查。
- 地面检查：`check_ground_seams.ps1`。
- 截图：`tools/capture_tree_basin_northwest.gd`，传 `--lookdev --expand-west`。
- 性能：`tools/profile_tree_basin_northwest.gd`，传 `--lookdev --expand-west`；`--perf-motion`为移动镜头，`--northwest-before`仅停用新增西北岸，保留树池修复。

原生验证、接缝、资产保护、性能结果均在 `renders/tree_basin_northwest/`。性能报告为当前机器1600×900、4×MSAA/TAA的短采样，不代表全校持续运行；退出时的7个Texture RID释放警告仍为既有问题。

本轮结果：8组场景QA全部通过、8树/504根部顶点与可见边框实测通过、12834地面接缝采样零缺口、115份既有文件保持。性能采样中窗口焦点切换，未满足严格同条件对比标准；原始数据保留，不据此宣称稳定帧率或通过性能回归。后续在空闲且窗口持续聚焦时复测。
