# 中国科学技术大学东校区 · 普通下午

当前空间主轴：老北门—玉泉北路（樱花大道）—眼镜湖双池—一鉴亭—第一教学楼。以已接受的一教Diorama为核心，接续真实北轴；最新范围与置信度见文末“北轴连续模块”。下文早期V0.1/0.2范围保留为迭代历史。

## 坐标和真实性

1 Blender unit = 1 Godot unit = 1米。OSM原点117.2634979E,31.8427261N（老北门）；经纬度转换为当地米制，再旋转使玉泉北路向南为+Z；X朝校园轴线东侧，Y向上。原始方位角与轮廓保存在 godot/assets/site.json。Blender生成时转换为X,-Z,Y，GLB标准导出转换回Godot。

一教北立面在原点以南约160–170米，东西约126米，南北最深约60米。平面是U形，不能做成一块方楼。门前瀚海路东西贯通，东侧天使路连通南侧勤奋路。一鉴亭在东池中北部，以折线桥连接岸边。双湖之间道路维持步行尺度约8米，树冠覆盖但保留视线。

数据分级：OSM平面高于人工摆放；官方照片外观高于地图楼层标签；未知项标注艺术估算。北门新入口不替代老北门；不混入西区图书馆或也西湖。

## 玩家与镜头

身高1.75米，眼高1.65米；步行1.8m/s，Shift慢跑4.2m/s，Space跳跃，鼠标环视，Esc释放／点击捕获。V切自由相机，Q/E升降。1–5切观景点，F隐藏界面，F12截图，G灰模对照，R回到老北门。

至少3张最终截图须来自Godot真实运行。截图点、FOV、朝向及构图目的自动导出至 renders/photo_spots.json，约16:10美术光照，非天文太阳模拟。

## 交付边界

建筑外部可探索，不实现教学楼室内；水体与岸边有行走保护；背景建筑不代表全校细节复原。V0.1优先空间、氛围和连续路线，人口动画与音效只做轻量环境生命，不承诺完整人群系统。

## 北轴连续模块 · 当前范围（2026-09-08）

本节更新当前可视范围；先前“固定160×120m”和“只保留双池末端”是早期样板的历史限制。本轮在保留一教Hero Area和既有角色资产的基础上，沿同一米制坐标接回老北门、玉泉北路、完整双湖、亭岛与一鉴亭、专家楼和3栋邻楼。不是整个东校区铺开，也不是复制一教建筑。

北轴地面以 `godot/data/north_axis_layout.json` 的不规则 `polygon` 为准：外包 x[-112,178]、z[-20,153]，多边形面积约 31,932m²，外包矩形不能当作实际可行走面积。东北住宅下方局部展宽至 x178；南边在 z118 接回既有核心，并与东花园有明确的小范围连接。建筑不因底座形状而缩小或移位。

新门中心(-1,2.65)，亭中心(42.501,80.789)。亭与所有曲桥的可走面统一 y=.34m，水面当前为 y=-.05m。东池包含真实亭岛孔洞，北/东两支桥连通亭岛；西池有曲桥与短支。桥面、坡道、亭面及陆地由环境模块统一承托，建筑实体/水体/底座外部为不可穿越区域。地面不是一块覆盖湖面的隐藏整平板。

研究依据从旧手描桥升级为归档 OSM bridge/water relation，并复核官方门、亭与湖照片；资料分级仍然成立。真实可信项是轴线、双池分列、亭的六角/红瓦/暖柱、桥路拓扑及邻楼平面。门楣深度、亭高、桥栏净高、窗格尺寸、专家楼完整立面与三栋邻楼楼高为照片比例或艺术推断。研究照片跨2016—2026年，场景不是某一日的严格现状测绘。

新增主建筑采用独立 `north_axis_architecture.glb`，周边采用 `north_axis_surroundings.glb`；场景中具体完成状态由本轮实际 Godot 运行、步行碰撞验证与截图报告决定。独立Blender proof只证明模型形体和导出前外观，不作为运行验收替代。
