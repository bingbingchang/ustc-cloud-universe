# 复原计划与实现依据

已完成资料检索、官方PDF视觉检查、OSM提取、卫星交叉检查、官方照片收集与核心区域选择。选择北段轴线是因为连续性强、双池与U形一教容易辨识、林荫和水面可形成不同镜头。郭沫若广场与新老图书馆留待V0.2，不用未经核查的现代大楼抢占本版资源。

实现顺序：数据驱动Graybox → 地面/池岸/建筑碰撞 → 人体尺度控制器 → Blender门、一教、亭桥GLB → 成组植被、小品 → NPR/天空/水/风 → 实际图形运行 → 截图与地图对照 → 修改 → 验证日志。

重点对照：双池东西位置、亭与专家楼前后、老门和一教同轴、一教南向U形、道路贯通、湖岸不漂浮、建筑不被树完全遮蔽。所有研究照片只作为外部参考，不能加载为最终游戏材质。

后续V0.2：一教立面实地尺寸补测、郭沫若广场轴线扩展、图书馆双楼区；以后再做更多建筑，不以扩大面积冒充精度提高。
