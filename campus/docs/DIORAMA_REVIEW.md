# Diorama 0.2 · 美术评审记录

2026-09-08；参考图已从工作区references/art_direction逐张读取。当前范围是一教—入口前场—樱花大道末段，160×120米。没有扩大校园地图。

## 参考分析到实际实现

参考中的收藏模型感来自整体轮廓、有限色板、大中小树冠体块、接地阴影与弱透视。上一轮逐叶堆积噪声的方向与此不同。本轮新增独立Diorama场景和资产，不复制神社、鸟居、角色或日式装饰。

- 保留一教米制坐标、四层体量、U形平面、窗列与入口关系。
- 三类树各三个个体：横展粉白樱花、高挑梧桐、纵向紧凑乔木。花团是连续多叶瓣曲面，主枝、次枝、大簇、中簇、小强调簇分层组织，少量嫩叶与18片克制飘落花瓣。
- 建筑凹窗与窗台、入口结构沿用并精化，新增后立面窗框和连续屋顶边界。Diorama建筑石材边缘约6.5cm倒角增强吃光，旧版资产仍保留原尺寸处理。
- 红砖削弱高频砖缝，草地与铺装压低斑驳，玻璃沿用独立PBR反射；统一灰蓝金属、米灰石材、暖木与粉白/自然绿。
- 暖太阳、冷灰天空填充、增强AO/SSIL、柔化阴影；原生4K捕获用8x MSAA、TAA、8192阴影。展示底座和中性背景为摄影呈现，不是新增校园地形。

## 四轮实机循环

1. `build_01.log / render_01.log`：首次完整五机位。发现正交留白过多、黑屋顶过重、草地噪声、花团顶部网格缺口、背面框架不完整。基线保存round01。
2. `build_02.log / render_02.log`：焊接花团极点、增加连续曲面采样、调整粉白比例与簇厚度；补后窗、屋顶边缘；压低草地噪声、调整背景和正交取景。检查发现屋顶边界交叉线过多、普通透视仍过小，近景有生硬地平线。保存round02。
3. `build_03.log / render_03.log`：屋顶改连续外轮廓；调整A/B和局部构图。按原岸线切回两处双池末端，未用草地抹掉水体。移除选区外的旧碰撞体，新增展示边界与入口碰撞。9项Diorama控制器回归通过，重拍五图。
4. `build_04.log / render_04.log`：池水反射降低镜面感，独立保存Blender Diorama源文件，更新春日HUD；再次生成五张4K图。

## 五机位的用途与A/B结论

| 图 | 摄影模式 | 评审重点 |
|---|---|---|
| 01 | 3/4正交，size150m | 完整模型边界、U形、入口轴线，首选总览 |
| 02 | 同方位/近同俯角，50°普通透视 | 前后尺度变化更强；不能把相机差异当作几何差异 |
| 03 | 44°中高位局部透视 | 花团、红砖、铺装树影与入口层次 |
| 04 | 46°入口中景 | 窗洞厚度、接触阴影、玻璃、雨棚与小品 |
| 05 | 44°南侧庭院透视 | U形背面完整性、庭院关系与屋顶收口 |

01更接近参考中的可收藏完整小世界。02保留空间透视的生命力。05为了不裁掉底座，把早期35°调整到44°，因此最终是较温和透视，不将其包装成真正正交镜头。元数据以photo_spots.json为准。

## 验证与性能

`renders/diorama/validation.json`：摄影→步行、轴线行走、接地、跳跃落地、入口碰撞、鼠标环顾、Esc、正交摄影、透视摄影，共9项通过。验证使用实际Godot控制器与物理帧；没有用旧场景151m报告代替新选区验证。

五张截图均为Godot原生3840×2160，未重绘、合成或放大。capture_report.json记录该轮实际采样帧率/绘制调用；它是捕获采样而非稳定性能基准。场内32棵树，实例化复用。当前4K高质量阴影与边缘几何仍有成本，未宣称完成LOD优化。

运行和截图没有阻止运行的错误；退出仍有7个Texture RID清理警告，沿用上一版已知限制，尚未声称定位原因。

## 美术结论与边界

本轮已经建立区别于上轮的Diorama方向，花团结构、连续柔边、受控纹理、模型总览和统一色系均可直接在实机看到。五张作为当前高画质评审/宣传候选图交付。

仍需持续精修：近距离花团与枝干接合可以更自然，后立面局部细部仍基于节奏推断，入口玻璃未制作完整室内。模型总览保持真实楼体长度，所以不像参考中的小神社那样紧凑；没有为模仿参考而缩短一教。庭院铺装、树位、地块截断和简化水深明确属于艺术化样板，不应视为实测数字孪生。

下一阶段继续在本Hero Area内推进；不以扩建替代美术收敛。

## 文件与复现

- `blender/source/ustc_diorama.blend`：Diorama集合显示，旧LookDev集合隐藏，共享小品独立集合。
- `blender/scripts/diorama_assets.py`：模型源逻辑；`build_assets.ps1`会构建并导出GLB。
- `godot/scenes/diorama.tscn`、`godot/scripts/diorama.gd`：独立实时场景及摄影/交互。
- `godot/shaders/diorama.gdshader`、`diorama_water.gdshader`：独立风格变体，旧版shader不覆盖。
- `run_diorama.ps1`：可加-Capture、-Ultra、-Verify；OPEN_DIORAMA.cmd便于双击启动。
