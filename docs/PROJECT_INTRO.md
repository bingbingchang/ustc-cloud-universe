# 科大云宇宙项目介绍

**校园数字空间——链接现实与虚拟。**

科大云宇宙希望让中国科学技术大学在云端拥有一个持续生长、可以进入、可以互动、可以共同创造的数字校园。从真实校园的空间还原出发，项目将逐步连接校园信息、数字身份、社群活动、科研展示与现实服务，形成面向师生、校友和访客的云端校园入口。

## 项目愿景

一座校园的价值，来自其中不断发生的学习、交流、研究和创造。科大云宇宙希望把这些连接带入数字空间：让一场讲座在对应场地被发现，让一个实验室的成果被更多人理解，让社团活动吸引新的参与者，让远方校友回到熟悉的校园，也让不同学科、不同届和不同地域的人找到共同的兴趣。

我们要探索的，是一个与现实校园共同生长的平台。空间提供共同语境，身份连接人与人，内容带来持续访问，服务推动现实行动。随着参与者创造和维护内容，云端校园将从可漫游的场景，逐步成长为可交流、可协作、可运营的校园数字世界。

## 现实需求与切入点

新生和访客需要理解校园、找到地点与活动；社团和活动组织者需要展示内容、招募参与者；实验室、科研团队和学生项目需要清楚表达成果；校友需要跨越地理距离保持校园连接。这些需求可以共享一套空间与身份基础。

第一阶段的平台服务将从真实校园活动切入：组织者发布活动并绑定校园地点，学生在数字空间发现活动、报名收藏、获得路线指引，再进入现实活动现场。这个闭环可以用实际参与、到场体验与持续使用情况验证。

## 未来产品版图

| 方向 | 计划建设的能力 | 对应现实价值 |
|---|---|---|
| 校园信息 | 空间化通知、活动发布、讲座赛事、地点详情、报名收藏 | 让信息更容易被发现和行动 |
| 数字身份与社群 | 师生校友身份、多人互动、交流组队、社团空间 | 让校园关系跨越时间与地域 |
| 科研与创新 | 实验室展厅、项目演示、成果展示、跨学科协作 | 增加知识传播与合作机会 |
| 教育与体验 | AI导览、校园问答、互动学习、远程参观 | 提供可进入的学习与认知环境 |
| 校园文化 | 建筑变迁、人物故事、毕业纪念、校友记忆 | 积累可探索的校园文化内容 |
| 现实连接 | 地点扫码、活动到场引导、移动端定位、AR探索 | 让数字内容推动现实参与 |
| 内容创作 | 地点编辑、展厅布置、活动工具、共同建设 | 让校园参与者持续创造内容 |

这些能力构成未来发展方向，将通过原型、试点和用户反馈分阶段实现。

## 当前可展示成果

项目已经完成中国科学技术大学东校区的可交互外部场景原型。已建地块按真实校界计算覆盖99.019%，最近一轮新增110栋外部建筑和410棵树。人物漫游、自由相机、区域跳转、米制坐标显示和截图定位已经可以体验。

原开发版本完成137条人物实走路线、约4.53公里的通行检查，15项定位与相机检查通过。Windows公开试玩版在同一校园空间基础上采用原创校园人物与动物，并为独立运行调整截图与资源加载。

当前成果支撑“校园空间与交互基础”这一阶段。信息发布、用户账号、真人多人互动和校园服务接口，将在后续版本建设。地理覆盖率不代表室内、立面细节或平台功能的完成度。

## 创新与建设路径

项目把多源校园数据、自动化场景生成和可交互体验连接起来。地图轮廓约束空间位置，GIS与影像帮助识别建筑与场地，Blender脚本生成资产，Godot运行场景；统一坐标让真实地点、虚拟位置和用户反馈能够相互对应。

未来的产品创新将围绕“空间、身份、内容、现实服务”的组合展开。用户可以从一个地点发现信息，从一项活动建立连接，从一个数字空间了解真实团队。AI能力将服务于导览、问答和内容辅助，移动端与AR能力将服务于现实连接。

## 应用与创业方向

项目可以探索高校数字空间建设与持续运营服务、学院和科研团队展示空间、校园活动数字化方案，以及面向社团和创作者的内容工具。学生和访客获得便捷体验，学校、机构或活动组织者根据实际服务价值选择合作。

创业验证将从具体试点开始：找到真实组织者，运行真实活动，记录用户发现、报名、到场和反馈的过程，再判断哪些能力值得投入、哪些服务能够形成持续合作。随着空间生产方法和运营工具成熟，再扩展到更多校园。
