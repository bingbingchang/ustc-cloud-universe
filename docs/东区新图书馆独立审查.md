1. **顶部白色构架侧边缺中柱。** 当前左右侧视中，每座塔顶构架侧边仅有两根角柱、一个大开口；参考侧视有两根中柱，形成三个开口。建议在两个构架的纵深方向两侧各补两根中柱，保持与正面柱距关系一致。
2. **入口门组仍为功能性近似。** 当前地上入口分为左右两组门，参考正面门组更集中于中央。若由游戏通行设计决定，应作为已知适配差异记录；不能据此宣称门组位置已逐项复刻。
3. **屋顶设备为近似布置。** 已具备多排机组、高箱、连接体和管道，但尺寸、不同设备的相对位置与转折管线仍不完全对应参考。现有图不足以核实实际设备规格。
4. **余下相似度差异以材质和细部为主。** 窗框仍较均匀、玻璃较暗且缺少参考中的丰富反射；石材分缝、橙色砖纹和设备表面仍较简化。不同渲染照明会影响这些判断，不建议单凭色差继续改动主体尺寸。
