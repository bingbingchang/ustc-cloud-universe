# 科大云宇宙发展路线

项目以“校园数字空间——链接现实与虚拟”为主张，从校园场景原型逐步建设信息、身份、互动和现实服务。各阶段以可运行成果和真实使用反馈推进。

## 第一阶段 校园空间与体验

已形成东区外部场景、人物漫游、自由相机、区域跳转和坐标反馈能力。继续完善建筑识别、入口与道路、地点命名、校园导览和使用体验，建立稳定的公开试玩版本。

## 第二阶段 校园信息与现实活动

建设地点信息、活动发布、内容管理、报名收藏和到场路线。选择社团或活动组织者运行真实试点，验证信息发现、报名和现实参与的闭环。

## 第三阶段 数字身份与多人互动

建设账号与身份、在线参与、交流组队、社团及实验室空间、活动互动与内容共建。让用户在校园空间中建立持续连接，并形成组织者可维护的内容与服务。

## 第四阶段 科研教育与校园文化

探索科研成果展厅、课程与学生项目展示、互动学习、AI校园导览、校史与建筑变迁、毕业及校友记忆。让数字校园成为知识传播、创新协作和文化积累的平台。

## 第五阶段 现实连接与跨校园网络

探索地点扫码、移动端定位、AR体验以及与获准接入的校园服务连接。沉淀可复用的校园场景生产和运营工具，拓展到更多高校，形成跨校园的交流、展示和活动网络。

## 首个服务闭环

活动组织者发布内容并绑定地点 → 用户在数字校园发现活动 → 查看详情、报名收藏 → 获取路线并参加现实活动 → 反馈体验并保持后续连接。

围绕这个闭环记录实际参与、到场体验、组织者维护成本和持续使用情况，作为后续功能与合作模式的依据。
