# 东区新图书馆多视图复刻记录

日期：2026-11-17。对象：东区新图书馆（OSM 284161541），不是老图书馆。

## 本轮实现

依据用户提供的正面、背面、左右侧、屋顶正投影和斜俯视共六张参考图，重建可在游戏中加载的三维外观。包含双塔和镂空冠顶、四层大窗与顶层分组窄窗、橙色砖立面、灰白分格板、金色“圖書館”字样、深门廊、双梯及中央下层入口外观、屋顶栏杆、青绿色屋面分格、成组空调、风管、高箱体、设备平台和橙色连接体。

模型不是把参考图贴在建筑表面：门框、窗框、台阶、设备、风机和文字均有实际几何。砖与石材的颜色、拼缝和凹凸图可由生成器重建。16 种材质、157 个分件、93,480 个三角形；游戏 GLB 约 16 MiB。

图中未提供实测尺寸。主体宽 72 m、深 25.5 m、主屋顶 24.3 m、塔顶 29.4 m、冠顶约 32.24 m，均为多图比例估算，不应当作测绘值。保留游戏原主入口校园坐标、3.18 m 平台；两组可互动门最后按参考居中到局部 X=±1.2 m。原始 OSM 轮廓保存在 source_osm_outline 中，避免将参考比例误记为原始地图数据。

## 独立审查与迭代

独立审查 agent 未参与模型实现，只收到六张参考和实际多机位渲染进行首轮盲审，随后复核修订结果。

- 第一轮：修复侧墙黑色缺口、两端石材边带不等宽、双塔无窗长凹槽；拓宽双梯，补连续门套与侧壁，增加按跨基座与背面分组窄窗。
- 第二轮：取消窗区上下多余白梁；缩短顶层窄窗、加厚上部灰墙；补屋顶橙色连接体、高箱机组、格栅平台和门框拉手。
- 验证机位：正、背、左右、顶视采用正投影，另保留斜俯视及游戏实际入口、侧面、门厅截图。单独外壳预览没有游戏运行时门厅，入口玻璃透过白色背景的现象须与游戏截图交叉判断。

详细独立意见见 `东区新图书馆独立审查.md`。这份记录不宣称像素级相同或实测 1:1：参考的书法笔迹、玻璃环境倒影、自然光、精确设备型号及实测尺寸仍不能仅凭这些图完全确定。当前文字使用楷体轮廓，室内保留原有可游览门厅，未把未提供的整栋内部布局编造成实景复刻。

## 游戏接入与验收

加载入口为 `campus/godot/scripts/library_district.gd`；只替换 `south_library.glb`。其他四栋库区建筑、道路、植被和铺装数据保持不变。新馆模型采用局部坐标，通过 manifest 定位回原校园入口；同步调整实体碰撞及地面挖空轮廓，避免旧宽轮廓留下空洞。

两处门的临时模型分件含 `PhotoVisitGlass`，游戏启动后隐藏这些分件并生成现有可开关门。透明材质使用 `PhotoLibraryReplica_` 前缀，避免通用旧材质覆盖。

验收：结构检查 22/22、真实玩家最终局部实走 36/36、完整校园检查 28/28 通过。包含两门 E 开关、关闭阻挡、从内侧开关、进出、防夹和双梯上下。首次整校运行在建模程序同时占用内存时出现内存分配失败；关闭 Blender 后完整校园重试通过。随后补齐 8 根冠顶侧中柱，并将门组居中。最终模型重新进行结构、局部实走及平台转向中央入口检查，刷新截图；完整校园报告对应这两项末次微调之前的模型，不能冒充最终模型全区复测。退出整校仍有项目已有 7 个 Texture RID 提示，本轮未修改无关渲染系统。
