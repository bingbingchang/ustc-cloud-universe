# 科大云宇宙首个公开试玩版

**校园数字空间——链接现实与虚拟。**

我们希望让真实校园在云端拥有一个持续生长的第二空间：在熟悉的场景中发现信息、遇见伙伴、展示成果，并把数字连接带回现实中的活动、学习与合作。

本次发布中国科学技术大学东校区三维校园原型。已建外部区域按真实校界计算覆盖99.019%，支持人物漫游、自由相机、区域跳转和坐标截图反馈。

## 下载与运行

下载 `USTC-Cloud-Universe-v0.1.0-alpha-Windows-x64.zip`，完整解压，双击 `USTCCloudUniverse.exe`。exe和pck文件须放在一起，无需安装Godot或Blender。首版面向Windows x86_64与支持Vulkan的桌面图形设备。

WASD移动、Shift加速、Space跳跃；V切换人物与自由相机，Q/E升降、滚轮调速。顶部菜单选择区域，7住宅、8校史馆、9科研区，R回北门。C显示坐标，F12保存截图及同名坐标JSON。

截图位置：`%APPDATA%\USTCCloudUniverse\screenshots`。独立程序已通过人物移动、相机升降、模式切换、区域跳转、定位面板与截图保存等10项验证。

## 当前与未来

当前版本提供空间与交互基础，建筑室内和部分场景细节仍在完善。信息发布、报名、数字身份、真人多人互动、科研展厅、校园文化、AI导览和现实服务联动，将按照发展路线逐步建设。

通过仓库Issues反馈场景问题、提交功能建议或交流合作想法。期待和更多校园参与者一起把云端校园做起来。
